# 星盤命盤占星計算應用程式 (Natal Chart & Synastry Astrolab)

一款具備夜空神秘美學、純 TypeScript 高精度天文計算核心與豐富繁體中文深度解析的**個人本命盤、雙人合盤（比較盤）與關係中點組合盤**排盤應用程式。

---

## 🌟 核心功能特色

### 1. 個人本命盤 (Natal Chart)
- **高精度天文排盤計算引擎（純 TypeScript 獨立模組）**：
  - 支援儒略日（Julian Day）與地方平恆星時（LST）天文轉換。
  - 計算十大行星與重要虛點：**太陽、月亮、水星、金星、火星、木星、土星、天王星、海王星、冥王星、凱龍星、北交點（命運之門）、莉莉絲（黑月）**。
  - 自動辨識行星逆行狀態（Retrograde ℞）與每日運行速度。
  - 支援四大軸點計算：上升點（ASC）、天頂（MC）、下降點（DSC）、天底（IC）。
  - 支援三大主流宮位系統：**普拉西度制（Placidus）**、**整宮制（Whole Sign）**、**等宮制（Equal）**。
- **互動式輪狀星盤圖 (Interactive SVG Chart Wheel)**：上升點固定於西方 9 點鐘位置，黃道逆時針展開，行星防重疊避讓與幾何相位連線。
- **星盤三巨頭速覽 (The Big Three)**：太陽、月亮、上升星座度數與心理畫像。
- **行星度數表與專業三角相位矩陣 (Aspect Grid)**。
- **繁體中文深度性格解讀庫**。

---

### 2. 雙人合盤 / 比較盤 (Synastry Chart)
- **雙同心圓輪盤（Bi-Wheel）**：
  - 內圈為盤主 A 的星盤與後天宮位（金色），外圈為盤主 B 的行星（水藍色）。
  - 中央動態繪製兩人行星交叉互照相位線（甜蜜吉相藍綠線、磨合張力紅橘線）。
  - 支援一鍵互換內外盤（A ↔ B）順序。
- **四維關係契合度量化評分儀表板**：
  - 綜合契合總分（0 - 100 分）。
  - 靈魂默契（日月互動）、激情吸引（金火火花）、思維溝通（水星頻率）、長久穩定（土星責任羈絆）。
  - 關係化學反應稱號標籤（如「天作之合·靈魂契合」、「致命吸引·火花璀璨」等）。
- **交叉相位深度解析與行星落入對方宮位分析**。

---

### 3. 關係中點組合盤 (Composite Chart)
- **劣弧幾何中點演算法（Shortest Arc Midpoint）**：
  - 精確計算兩人天體在黃道上的最短弧中點，代表「這段關係本身成了一個新生命體後的命運本質」。
  - 組合上升（Composite ASC）與組合天頂（Composite MC）宮位系統。
- **組合盤三巨頭與使命解讀**：
  - 組合太陽（關係的核心目標與人生追求）。
  - 組合月亮（相處時的情感心境與安全感）。
  - 組合上升（這段關係呈現給外界的公眾形象）。
- **組合盤專屬輪狀圖、行星度數列表與相位矩陣**。

## 🛠 技術棧架構

- **框架**：React 18 + TypeScript + Vite
- **樣式**：Tailwind CSS + Lucide Icons + Canvas Confetti
- **天文計算**：自研純 TypeScript 天文演算法（Meeus / JPL Keplerian / ELP-2000 月球攝動論 / 劣弧中點法）
- **向量渲染**：原生 SVG 雙同心圓互動式輪狀星盤
